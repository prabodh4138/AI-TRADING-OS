# AI Trading Operating System (AI-TOS)

Local-first positional trading research and paper-backtesting platform for NSE-style OHLCV data.

**Current production baseline:** data ingestion, technical indicators, explainable positional scanner, risk sizing, no-lookahead backtester, Streamlit dashboard, PostgreSQL/Alembic foundation, tests, and environment-safe configuration.

See `docs/Production.md` for setup and operational controls.
